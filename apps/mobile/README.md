# Мобильное приложение

Expo (React Native), TypeScript. Экран «Сегодня»: ось дня из плана, две крупные
кнопки, прогресс недели против цели и полоса недели с отметками.

## Запуск

```
cd apps/mobile
npx expo start --ios --port 8100
```

Бэкенд должен быть поднят: `pnpm api` в корне (порт 4318). Симулятор ходит в
`localhost` хоста напрямую, настраивать ничего не нужно.

Порт указан явно, потому что 8081 у Expo по умолчанию и часто занят другим проектом.

## Чего пока нет

Локального кэша и офлайн-очереди: запись оптимистична в памяти, но при отсутствии
сети теряется. Это переедет в `packages/core` вместе с API-клиентом — тогда офлайн
заработает и на вебе, и на телефоне из одного места.

Плана на неделю целиком, месяца и года — сейчас только «Сегодня» и полоса недели.

## Заметки по окружению

`apps/mobile` намеренно не входит в `pnpm-workspace.yaml`: Expo управляет своими
зависимостями через npm, и два менеджера дерутся за `node_modules`.

Metro определяет монорепу по `pnpm-workspace.yaml` и требует, чтобы `node_modules`
в корне существовал, — иначе падает с `Failed to construct transformer`. Держи
корневой `pnpm install` выполненным.
